# Happy Birthday Vishal! ❤️🎂

A cute, handmade-style pastel birthday surprise website crafted for Vishal.

## Features

1. **Opening Surprise Screen** (`Hey Vishal! ❤️` + `CLICK HERE 🎁`)
2. **Main Birthday Page** (Personal letter, floating photos from `img/`, and `ONE SPECIAL GIFT FOR YOU 💌` trigger)
3. **Special Gift & Secret Question** (`Where will you find her?` → unlocks `OPEN YOUR SPECIAL GIFT 🎁`)
4. **Horizontal Photo Carousel** (All real photos from `img/` & `gi/`, continuous right-to-left motion, hover pause, mobile swipe, tap-to-zoom)
5. **Romantic Envelope, Love Letter & Forever Promise** (`WAIT... THERE'S ONE MORE THING 💌` → animated envelope → `MY DEAREST VISHAL ❤️` → `OUR LITTLE FOREVER PROMISE ❤️` → `YES, ALWAYS ❤️` / `A THOUSAND TIMES YES! 🥹` → `Her Signature` drawing pad & `SEAL OUR PROMISE ❤️`)

## Adding Happy Birthday Music

Place your classic **Happy Birthday to You** MP3 at:

```text
audio/happy-birthday.mp3
```

## Running Locally

```bash
python -m http.server 8765
```

Open `http://127.0.0.1:8765` in your browser.
